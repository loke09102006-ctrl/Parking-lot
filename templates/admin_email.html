SMTP Email Setup {{ 'CONFIGURED' if smtp_configured else 'NOT SET' }}

Email receipts are sent automatically after checkout when the customer's email is captured at entry. Configure the following environment variables on your server to enable this feature.

Environment VariableCurrent ValueExample
SMTP_HOST {{ smtp_host }} smtp.gmail.com
SMTP_PORT {{ smtp_port }} 587
SMTP_USER {{ smtp_user if smtp_user else '(not set)' }} yourmail@gmail.com
SMTP_PASSWORD •••••••• App Password
SMTP_FROM (defaults to SMTP_USER) ParkOS <mail@...>
UPI_ID (optional) yourname@upi
Gmail Quick Setup
  1. Go to Google Account → Security → 2-Step Verification → App Passwords
  2. Create an App Password for "Mail"
  3. Set SMTP_USER=yourmail@gmail.com
  4. Set SMTP_PASSWORD=<16-char app password>
  5. Restart the app — emails will be auto-sent after every checkout with a customer email
